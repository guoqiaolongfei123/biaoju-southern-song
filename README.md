# 镖局 · 风云行

根据《镖局》游戏概念设计 v0.1 制作的南宋天下可玩原型。它验证的核心体验是：接镖时仍是国内路线，赶路途中边城易主，玩家必须在新的国界条件下重新权衡信用、时限、银两与战斗损失。

项目拥有独立的云端发布与源码仓库，不复用、覆盖或依赖《律师模拟器》的部署环境。Windows 下可运行 `publish.cmd` 完成全量测试并生成可部署版本。

## 当前可玩内容

- 以约公元 1208 年为背景的完整中国舆图，包含真实海岸、山脉与主要水系
- 临安府、建康府、襄阳府、成都府、泉州、广州等 73 个历史城市站点
- 城池图标随缩放分三级展开：天下总览以城楼与驿点防重叠，州府详览逐步展开重镇，驿路近览显示全部城驿；当前城、分号与任务节点始终优先显示
- 99 条跨区域官道、山路与水路
- 舆图可在“通览／驿路／天候”三层间切换：驿路层强化官道实线、山路断纹与水路水纹，天候层以区域水墨、天象牌和同色道路显影标出实际受影响路段
- 城名、路况章、边界章、关渡、行旅与天候牌共用统一避让顺序；总览自动合并密集城驿、关渡和同行队伍，点击数字印即可放大展开，近览则只保留军队与同行镖旗的常驻姓名，减少重复文字堆叠
- 宋、金、西夏、大理、吐蕃与蒙古诸部势力分区
- 连续推进的边境战线：敌对城池相邻才会由“边声渐紧”依次进入围城、两军争城与换旗；守势、兵压、阶段日数与下一步风险均可查阅，玩家运送军需或援助边城可暂缓恶化
- 城市易主、今报/旧报/传闻三级动态情报和世界驿报；易主后会连带关闭失效网点并改变路线、路引与边关处置
- 天下商旅、军巡、同行镖局与宋金行营会沿真实道路逐日行进；军队只在友城与敌对前线之间选路，敌军趋城会抬高兵压、援军趋城会增加守势，位置与行军方向均随存档保留
- 旅途中会与地图上的真实行旅相遇：可与商队并旗换报、借友军巡骑清道、受敌骑盘查或绕行，也可同其他镖局合旗或竞速争名；撞见大军行营时还要在军例受验、卸旗绕营、冲破前锋或随营同道之间取舍
- 天下镖行榜会持续记录顺风镖行、江东忠义行与蜀川通远行的真实路线、到站交割、名望阶位、成镖／失期和与本号的关系；同行只在地图旗号真正抵站后成长，合旗增交情、争先伤和气，旧存档会自动补齐三家行号与地图镖旗
- 目的地易旗后的到城交割抉择：守原约、向新政权登记或凭调查与潜行秘密交割，分别改变封条、酬金、信用和双方关系
- 随机镖榜与三种路线方案；候选行程会直接叠绘在舆图上，以壹／贰／叁路签、不同线色与线纹标出途经城、中继驿、预计日数、路险和历史边关，悬停地图路签或右侧方案即可同步比较
- 行前成行判断：每条候选路线会把期限余量、现有行粮、全程马力和主副战阵合为一张判语，直接指出预计误限、途中补粮、歇马需求、旧报与路引缺口；危险路线仍可强行选择，但不再要求玩家自行心算一串数字
- 跨境身份构筑：行前可亮旗正行，或备办商旅行票、香客行脚、行院军差；镖单性质、随员职司与籍贯、副货和已知底细共同形成适配度，边关会公开被识破概率，败露后身份作废并触发自动战斗
- 地域副货经营：临安版刻、江南绫罗、淮盐、蜀茶、海舶香药、湖广粮米等按真实产地轮换；可在行前搭载，抵达后根据路程、城况与货损结算盈亏
- 三种行程方略：按旗稳行、昼夜兼程与偃旗潜行，分别改变时日、耗粮、马力、盘查与战斗压力
- 多段旅程会在中继城外进入驿亭、山店或渡亭，可整顿人马、补买路粮、核验下一程路报并临时改换行策；还可依据最新天气、封路、战线与边关重绘全部余程，比较新方案的时日、粮耗、马力和路险，而已经走过的路、伤势、货损、破封与胜战记录全部保留。若局势已经无力挽回，可正式转托有交情的同行、原路退回托镖城或认赔弃镖；同行副队按其真实地图脚程赶来，回程会推进天下，副货也按实际收队城市结清
- 货镖、信镖、活镖、特镖四类委托与十六组内容模板；每单具有允损、保密、赔付、可疑征象和隐藏变数。特镖包含冷藏通风、归柩禁验、刻时交付与引势追踪四种公开规程，会真实改变天候货损、边关风险、战斗敌势与误期扣酬，并可由随员、车具、行策和路线选择抵消
- 接镖前“账房试算”：镖榜会按当前车、马、人手、已知道路与沿途天气，为每张委托公开最可行脚程、期限余量、路粮、边关、路险和日均镖酬，并把真正适合现状的镖单排在前面；高酬但明显误期的委托不会伪装成好选择
- 镖单调查：可花银访查，也可违约验货承担信用与酬金损失；知情后会解锁新的边关处置
- 路线熟稔系统：反复走镖会沉淀为熟路并降低后续补给消耗与战斗压力
- 城市网点经营：出身城市总号、各城暗桩与可升级分号，提供自动路报、整备折扣和额外镖榜
- 政权往来与路引：在府城拜会行院、经营宋金等势力关系、申领限期通行文牒，并改变整备、酬金、关税与抽验风险
- 三阶“总号志业”贯穿单局经营：逐阶盖印领奖，达成“名镖天下”后形成正式通关卷；信用崩溃、队伍离散或车粮俱尽会在结算后触发对应败局
- 跨局“祖业谱牒”：四种胜败结局会永久收录旧客保状、旧部腰牌、牙行赊帖或天下旧路谱；新开镖局时择一携带，为信用、初始队员阅历、周转家底或总号熟路提供差异化开局
- 行号风骨会把长期选择沉淀为江湖名声：调查、守印、活镖交付、暗渡与付费开路可形成五种风骨，并反过来改变访查价格、镖榜类型、对应酬金和边关处置
- 三种可选镖局出身：临安“行在旧号”、襄阳“边军旧部”和泉州“海商联号”，各自拥有不同总号城市、车马、人手、资金与势力关系
- 风雨、难民、坏车、路报、匪徒与边关等途中事件，以及由镖单隐藏变数驱动的五类“镖物异动”：货箱错位、军需征发、尾随追踪、假吏验货与改札交货；随员职司、已知底细、行程方略、车具和资源储备会解锁不同对策
- Phaser 俯视护车战：突破关口、停阵守渡、活镖抢时入城三类目标；斩缰手、钩索手、弓手与火手会分别盯上马匹、车货和队员
- 全自动护车战：镖头与队员自行寻敌、走位、出招，玩家只下达临机应变、强行开路、围车固守、护住马匹与鸣金撤退等策略指令
- 活镖实体护送：护送对象会以独立人物单位随车移动、躲避并承受伤害；劫人者会绕阵追人，危急时可下“护住活镖”令让全队自动收拢、优先截劫。人身气血会跨路段保留，影响战报、最终镖酬与失镖赔付
- 战场自动抢修：受损镖车会以真实车况进入战斗；玩家只需下“停阵抢修”令，车把式便会自动脱阵赶到车轴旁作业，其余人继续守车迎敌。固轮挠钩、备用车轴与岗位绝活会影响抢修速度和恢复量，修复结果会写回后续行程
- 战前战术预案：开战前可在“雁行争锋、铁桶护镖、偃月钩连”中择一布阵，分别改变人手站位与移速、镖师攻势、车马承伤、车速、命中阻敌和绝技回转；临场阵令仍可即时覆盖当前护卫重点
- 南宋水墨战斗美术：镖头四帧枪术、三类随行镖师、四类敌人、双马篷车，以及江南官道、山口驿路、长江渡口三类战场均采用统一的手绘体系，并带有完整攻击帧、箭矢与火把飞行、钩索牵扯、伤害字、受击火花、倒地、绝技震屏和阵形光圈反馈
- 器械战场徽记：每名镖师身旁会显示所携弩、盾、药具与护车／护马器械印；对应阵令传到或装备自动发动时会亮起，谱样精校阶位会化为一至三道金色校痕，让人物养成与装备效果直接呈现在战场上
- 阵形自动连携：两名镖师压住同一敌手且近侧同伴招式已就绪时，会按行进、围车或护马阵自行使出夹击、护阵或合围；双人弧线、合击印、战场记功与 HUD 计数同步反馈，人物阅历会扩大接势窗口、缩短回转并提高追加攻势
- 状态驱动的击破演出：镖头、镖师和敌人会按真实受击脉冲后仰压身；气血归零时再由模拟时间派生渐进倒伏、墨尘飞散、落地墨迹与“伏／伤”印。匪首拥有更沉重的倒旗时长、“破”印和克制镜头推拉，减少动态效果模式则直接收敛到最终姿态
- 固守战分拨来敌：渡口与据车固守会按时限推进多拨援敌，并用战场急报提示斩缰手、火手、钩索手与弓手威胁，迫使玩家在自动交战中持续调整阵令
- 阵令直接改变自动行为：行进、围车与护马各有独立的镖头追击范围、镖师阵位、车马速度与减伤规则；战场会标出阵位、推进方向及弓手、斩缰手、钩索手、火手等高威胁目标
- 敌方危险起手预警：弓手、斩缰手、钩索手与火手会先锁定真实目标，再以目标线、收束圈和起手姿态公开攻击意图；阵令、绝技、齐射与器械都能在命中前自动截断威胁，玩家只需决定护车、护马、护人或强攻的战斗策略
- 阵令应招结算：危险起手真正命中车、马或活镖时，会按当前阵令判为「应」或「破」；护马卸刀、围车卸力和近卫截劫拥有独立战场印、记功签、HUD 得失计数与战后应对记录，让玩家能直接判断自己的策略是否对症
- 身后判定与自动脱围：总镖头即使停步也会持续锁定当前敌人；背后近敌会触发自动回身，三面受敌时会保持正面迎敌并侧退寻隙，副镖头在近侧会插入背袭路线、减伤并反打。战场弧线、护背计数与“回身／封背／中袭”记功签会公开全过程
- 阵令因果判词：最近一次危险起手会以“来招 → 我令 → 结算”持续留在战场底部，明确记录敌招目标、当时生效的阵令、实际承伤及下一招建议；暂停审势时判词仍会保留，主角与副镖头则使用带姓名的“主／副”核心名牌，方便追看两人的自动合击与截锋
- 审势节奏与暂停观阵：车、马或活镖遭危险锁定时会自动降至半速，留出约 1.4–2.1 秒的真实决策窗口；玩家也可在审势、常阵、疾战三档间切换，或停阵查看局势并继续调整阵令，标签页隐藏或窗口失焦时会自动暂停
- 情境救援阵令：队员倒地后“临机应变”会变为“收阵救人”，最近的可用镖师将自动脱阵、拖回并包扎同伴；医师、金疮药囊与人物战力会改变救援速度和起身气血
- 夺镖追逐战：快腿贼会携镖向出口脱逃；追击阵自动集中截人，停阵则优先保住余下车货，追回与失镖会产生不同战报和货损
- 高危山寨匪首：独立札甲旗首立绘会在危险伏击中发号，使附近群匪短时加速增伤；强行开路自动追斩匪首，旗倒后群匪强化立刻解除并陷入短暂溃乱
- 战后结算卷：胜负判定后保留战场，逐项展示镖头、队员、车马、货物与封条损失；玩家确认收阵后才把伤损写回旅程与名册
- 三套镖头武学构筑：岳门拒马枪震开群敌、断索快刀追斩劫车者、缠拿短手制住近敌；行前切换，战中按威胁自动择机施展，也可下令保留绝技
- 人物养成与器械架：镖师通过走镖和演武积累阅历、晋升阶位；熟手可在踏阵先锋、镇车执旗、游阵策应三条战职中定职，老手会按岗位领悟镇场传令、穿阵飞脚、阵前回生等七类绝活并自动执行；兵刃、护具、行具可购买并在队员间调配，同式器械谱样还可投入银两依次修整、精校、升为名匠制式，持续强化基础数值及弩击、药疗、钩牌、抢修等自动动作
- 主角成长页采用“主战修习 → 搭档与阵法 → 行装器械”三章式信息层级，并按组件自身宽度自动降列；右侧窄栏和手机界面都会完整显示武学、主副默契、阵历、装备效果与操作，不再用省略号藏住关键数值
- 城市右栏采用“城情／接镖／整备／人物”四章工作台：城况、繁荣治安与关系始终可扫读，“今日先办”会按真实伤势、马力、余粮和车况指出最迫切行动并直达对应章节；各章保留完整说明，但不再让镖榜、车马铺和人物养成同时挤成长页
- 胜阵战利器：旅程会记录真实胜战；凶险镖单只有在打赢护车战并以甲／乙交割后，才会获得朔边钩镰枪、神臂样弩、行军针药匣或黑漆团牌。精品不可花银购买，并继承齐射、救治、护马与举牌等自动战斗动作
- 持久伤势与诊治：自动战斗中的重度承伤会形成刀创、筋骨扭伤、骨伤或内伤，继续削弱队员战力并拖慢行程；伤势可随时间、驿站整顿和城市延医逐步恢复，战报与人物名册都会标明伤情
- 器械自动支援：踏张弩会在战场上自行点杀高危敌手，金疮药囊会救治阵中重伤者，护马短钩、固轮挠钩与藤牌则会在对应阵令下打断威胁；弩矢、药效光圈、器械印记、队员状态签与战报均提供可见反馈
- 攀车者两段威胁：专手会先借轮翻上车尾，再以第二招撬封夺货；独立“攀”字敌印、贴车姿态、攀附／撬封进度和“来招 → 我令 → 结算”判词会持续示警，围车时附近车把式或固轮挠钩持有者自动将其掀落
- 战阵记功签与传令演出：玩家每次改下阵令，号令会从镖头逐人传到随行镖师；战前预案、老手绝活、精品器械、集中齐射、救援、抢修和旗号急报会在战场边缘短暂署名，明确说明是谁自动响应、执行了什么以及产生了何种结果
- 集中齐射阵令：匪首、夺镖者、成排弓手或贴近车马的专手进入弩程时，临机阵令会转为“集中齐射”；持踏张弩的队员自动停阵取准、同步发射并短时制住目标，其他人仍按预案守车，齐发后自动恢复常态战术
- 战斗结果回写地图，并按货镖、信镖、活镖、特镖各自重视的时限、货损、封条、人身安全或特殊规程进行非二元结算与失败赔付
- 可抽取或手动输入天下签数；同出身同签可复现，IndexedDB 自动存档
- 桌面、触屏布局与减少动态效果支持

## 操作

- 地图与事件：鼠标或触屏
- 战斗无需操作人物移动或出招；点击阵令即可实时切换全队策略
- “观阵节奏”可切换审势、常阵、疾战；危险目标被锁定时会自动放缓，点击“暂停”可冻结战局但不锁住阵令
- 绝技默认自动择机施展，也可切换为“保留绝技”
- 形势不利时可点击“鸣金撤退”

## 架构

- `src/core/`：可序列化的纯 TypeScript 世界、旅行、委托与结算规则
- `src/battle/simulation.ts`：独立于渲染器的实时战斗规则
- `src/battle/PhaserBattle.tsx`：Phaser 输入与画面适配层
- `src/components/WorldMap.tsx`：React + SVG 南宋天下舆图
- `src/App.tsx`：流程编排和 DOM 界面
- `tests/`：可复现签数、出身、路线、城市易主、结算和战斗规则测试
- 开发环境可直接在地址后加入 `?map-preview=routes` 安全预览三案舆图对比，加入 `?map-preview=frontline` 检查争城、围城、宋金行营与战线军情，加入 `?rival-preview=all` 检查三家同行镖局的真实路线、名次和关系；或加入 `?event-preview=army`、`?event-preview=intrigue`、`?event-preview=stopover` 独立检查军阵拦路、镖物异动与中途余程重绘；加入 `?battle-preview=moments`、`?battle-preview=pursuit`、`?battle-preview=banner`、`?battle-preview=rescue`、`?battle-preview=client`、`?battle-preview=boarder`、`?battle-preview=defense`、`?battle-preview=rear`、`?battle-preview=repair`、`?battle-preview=volley`、`?battle-preview=growth`、`?battle-preview=leader`、`?battle-preview=equipment`、`?battle-preview=refinement` 或 `?battle-preview=coordination`，无须准备战斗存档即可独立试玩战阵记功签、追逐战、夺旗／士气战、倒地救援战、活镖护人战、攀车撬封战、阵令应招战、身后判定与自动脱围、断轴抢修战、集中齐射战、人物晋阶战、高危匪首战、器械自动技、谱样精校或阵形连携演示；加入 `?settlement-preview=equipment` 可安全预览胜阵获器结算，加入 `?crew-preview=discipline` 可独立预览战职、绝活、伤势、装备精校与演武界面；加入 `?legacy-preview=all` 可预览全部祖业传承的开局选择界面；加入 `?ending-preview=great-escort` 可用当前存档安全预览结局与谱牒收录卷

地图地理骨架采用 Natural Earth 公共领域矢量数据；历史地名体系参考 Harvard CHGIS，并借鉴南宋绍定、淳祐时期舆图的山川与州府并重表达。

项目刻意没有引入后端和账号系统；当前版本先验证“变化的国界是否真的改变押镖决策”。
